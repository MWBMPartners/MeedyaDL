# Tastaturkürzel

MeedyaDL unterstützt Tastaturkürzel für schnelles Navigieren und häufige Aktionen.

## Navigation

| Tastenkombination | Aktion |
|----------|--------|
| **Cmd/Ctrl + D** | Wechselt zur Download-Seite und setzt den Fokus in das URL-Feld |
| **Cmd/Ctrl + Q** | Wechselt zur Queue-Seite |
| **Cmd/Ctrl + L** | Wechselt zur Library-Seite |
| **Cmd/Ctrl + H** | Wechselt zur History-Seite |
| **Cmd/Ctrl + K** | Wechselt zur Activity-Seite |
| **Cmd/Ctrl + ,** | Wechselt zur Settings-Seite |

## Aktionen

| Tastenkombination | Aktion |
|----------|--------|
| **Enter** | Startet den Download (wenn das URL-Feld fokussiert ist) |
| **Shift + Enter** | Fügt im URL-Feld einen Zeilenumbruch ein (Modus für mehrere URLs) |
| **Cmd/Ctrl + Shift + .** | Bricht jeden aktiven und wartenden Download ab |
| **Cmd/Ctrl + Shift + ?** | Öffnet diese Tastaturkürzel-Übersicht von überall in der App aus |
| **Escape** | Schließt das aktive Modal-Fenster oder den aktiven Dialog |

## Hinweise

- Verwenden Sie unter **macOS** die **Cmd**-Taste (⌘)
- Verwenden Sie unter **Windows/Linux** die **Ctrl**-Taste
- Tastenkombinationen sind deaktiviert, während Sie in ein Textfeld tippen, um versehentliches Navigieren zu verhindern
- Das Activity Log unterstützt Textauswahl und Kopieren (Cmd/Ctrl + C)
- **Cmd/Ctrl + D** wechselt zur Download-Seite und setzt den Cursor in das URL-Feld. Was dort bereits steht, bleibt unverändert.

## Modal-Tastenkombinationen

Wenn ein Modal-Dialog geöffnet ist (z. B. Absturzbericht, Dateiauswahl):

- **Escape** schließt das Modal-Fenster und gibt den Fokus zurück an den Hauptinhalt.
- Die Tab-Taste bewegt den Fokus durch die fokussierbaren Elemente innerhalb des Modal-Fensters (Fokus-Falle).

## Barrierefreiheit

- **Tab** bewegt den Fokus vorwärts durch die interaktiven Elemente.
- **Shift + Tab** bewegt den Fokus rückwärts.
- Der Link "Skip to main content" erscheint beim ersten Drücken von Tab (oben links).
