# Raccourcis clavier

MeedyaDL prend en charge des raccourcis clavier pour naviguer rapidement et effectuer les actions courantes.

## Navigation

| Raccourci | Action |
|----------|--------|
| **Cmd/Ctrl + D** | Ouvre la page Download et place le curseur dans le champ d'URL |
| **Cmd/Ctrl + Q** | Ouvre la page Queue |
| **Cmd/Ctrl + L** | Ouvre la page Library |
| **Cmd/Ctrl + H** | Ouvre la page History |
| **Cmd/Ctrl + K** | Ouvre la page Activity |
| **Cmd/Ctrl + ,** | Ouvre la page Settings |

## Actions

| Raccourci | Action |
|----------|--------|
| **Enter** | Lance le téléchargement (quand le champ d'URL a le focus) |
| **Shift + Enter** | Insère un retour à la ligne dans le champ d'URL (mode multi-URL) |
| **Cmd/Ctrl + Shift + .** | Annule tous les téléchargements actifs et en attente |
| **Cmd/Ctrl + Shift + ?** | Ouvre cette liste de raccourcis clavier depuis n'importe où dans l'application |
| **Escape** | Ferme la fenêtre modale ou la boîte de dialogue active |

## Remarques

- Sur **macOS**, utilisez la touche **Cmd** (⌘)
- Sur **Windows/Linux**, utilisez la touche **Ctrl**
- Les raccourcis sont désactivés pendant la saisie dans un champ de texte, pour éviter une navigation accidentelle
- L'Activity Log prend en charge la sélection de texte et la copie (Cmd/Ctrl + C)
- **Cmd/Ctrl + D** ouvre la page Download et place le curseur dans le champ d'URL. Ce qui y est déjà saisi reste tel quel.

## Raccourcis dans les fenêtres modales

Lorsqu'une fenêtre modale est ouverte (par exemple, un rapport de plantage, un sélecteur de fichier) :

- **Escape** ferme la fenêtre modale et redonne le focus au contenu principal.
- La touche Tab fait défiler le focus parmi les éléments pouvant le recevoir à l'intérieur de la fenêtre modale (piège de focus).

## Accessibilité

- **Tab** déplace le focus vers l'avant parmi les éléments interactifs.
- **Shift + Tab** déplace le focus vers l'arrière.
- Le lien « Skip to main content » apparaît dès la première pression sur Tab (en haut à gauche).
